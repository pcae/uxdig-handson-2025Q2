# TechStack for This Project

## Language and Framework

- TypeScript
- Next.js - App Router(ver15.x)

## UI library

- Shadcn/UI

## Styling

- Tailwind CSS

## Architecture

- Modular Monolith Architecture
  - Clear module boundaries
  - Explicit module interfaces
  - Independent module development

## State Management

- Jotai(v2.x)
  - Module-specific state management
  - Shared global state when necessary
- Tanstack Query (React Query)
  - API data fetching and caching
  - Module-specific query hooks
